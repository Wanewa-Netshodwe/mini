# Mini

**Mini** is an AI agent personal assistant built for recruiters. It manages appointments, schedules interviews, and handles other day-to-day recruiting activity — all from a native desktop app.

Mini isn't limited to the desktop, though. You can prompt it from anywhere via **WhatsApp** or **email**, and it'll carry out the task and keep everything in sync with the app.

## Features

- 🗓️ **Appointment & interview scheduling** — book, reschedule, and manage interviews without touching a calendar app directly
- 🤖 **AI agent core** — understands natural-language requests and turns them into actions
- 💬 **Remote prompting via WhatsApp** — message Mini on the go and it executes the task
- 📧 **Remote prompting via Email** — send Mini an email and it responds and acts accordingly
- 🖥️ **Native desktop app** — built on Electron for a fast, always-available experience
- 🔄 **Cross-channel sync** — actions taken via WhatsApp or email reflect instantly in the desktop app

## Tech Stack

This is an Electron application built with React and TypeScript.

## Project Setup

```bash

```

### Development

```bash
$ npm run dev
```

### Build

